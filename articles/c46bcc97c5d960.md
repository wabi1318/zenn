自分的によさそうな設定手順の備忘録。
ネット上に情報が多く、また慣れてもいるeslintrcで設定を行っている。なおFlat Configがv9ではデフォルトとなりeslintrcはv10で削除されるので注意。

# 環境
- Node.js: v20.15.0
- ESLint: v8.57.0(npx eslint —init でバージョンが上がる？)
- Prettier: v3.3.2
- Jest: v29.7.0
- husky: 9.0.11

# 各オプション解説
## root
eslintコマンドを実行したディレクトリを起点に、ディレクトリをさかのぼって設定ファイルを探す仕様がある。
```true```に設定することで、この記述がある設定ファイルが見つかるとそれ以上さかのぼらなくなる

## env
envはチェック対象のJavaScript/TypeScriptコードがどの実行環境で使われるかをESLintに伝えるためのオプション。ESLintのno-undefルールに関係するため正しく設定しよう

## parserOptions
### ecmaVersion
チェック対象のJavaScriptがどの構文を使っているかをESLintに伝えるためのオプション。nvオプションでes2022などECMAScriptのバージョンを指定している場合、ecmaVersionにも自動的にes2022が設定されるため省略可能。

### sourceType
JavaScriptコードがスクリプトモードとモジュールモードのどちらのモードで書かれるかを指定するオプション。通常モジュールモードで開発する。

# 設定手順
## ESLintの設定
1. eslintをダウンロード（少し古いバージョンなのはnpx eslint —initを使うため） 
```
npm i -D eslint@8.2.0 
```
    
2. npx eslint —init でセットアップ
```
√ How would you like to use ESLint? · style
√ What type of modules does your project use? · esm
√ Which framework does your project use? · react
√ Does your project use TypeScript? · No / Yes
√ Where does your code run? · browser
√ How would you like to define a style for your project? · guide
√ Which style guide do you want to follow? · standard
√ What format do you want your config file to be in? · JSON
```
    
3. .eslintrc.jsonの修正
```js
{
  "env": {
    "browser": true,
    "es2022": true
  },
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:@typescript-eslint/recommended-requiring-type-checking",
    "standard",
    "plugin:react/recommended"
  ],
  "parser": "@typescript-eslint/parser",
  "parserOptions": {
    "ecmaFeatures": {
      "jsx": true
    },
    "ecmaVersion": "latest",
    "sourceType": "module",
    "tsconfigRootDir": "__dirname",
    "project": true
  },
  "plugins": [
    "react",
    "@typescript-eslint"
  ],
  "rules": {},
  "settings": {
    "react": {
      "version": "detect"
    }
  }
}

```
    
4. 各種プラグインを導入
```
npm i -D eslint-plugin-jsx-a11y eslint-plugin-react-hooks jest eslint-plugin-jest
```
    
5. .eslintrc.jsonの修正
```diff js
{
  "env": {
    ...
+    "jest/globals": true
  },
  "extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:@typescript-eslint/recommended-requiring-type-checking",
    "standard",
+    "plugin:jsx-a11y/recommended",
    "plugin:react/recommended",
+    "plugin:react/jsx-runtime",
+    "plugin:react-hooks/recommended",
+    "plugin:jest/recommended",
    ...
  ],
  ...
  "plugins": [
    "react",
+    "@typescript-eslint",
+    "jsx-a11y",
+    "react-hooks",
+    "jest",
    ...
  ],
  "overrides": [
    {
      "files": ["*.tsx"],
      "rules": {
        "react/prop-types": "off"
      }
    },
+    {
+      "files": [
+        "src/**/test/**/*.{js,jsx,ts,tsx}",
+        "src/**/*.{test,spec}.{js,jsx,ts,tsx}"
+      ],
+      "env": {
+        "jest/globals": true
+      },
+      "extends": ["plugin:jest/recommended", "plugin:jest/style"],
+      "plugins": ["jest"]
+    }
  ],
  ...
}
```
    
6. settings.jsonを開き、以下を設定
VS Code でコーディング中にも ESLint が走るように設定するため。
```js
"editor.defaultFormatter": "esbenp.prettier-vscode",
"editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit",
    "source.fixAll.stylelint": "explicit"
},
"editor.formatOnSave": false,
"typescript.enablePromptUseWorkspaceTsdk": true,
```
    
7. .eslintignoreをルートに作成し、以下のように記述
```js
vite.config.ts
```
    
8. packege.jsonに以下を追加
```jsx
"scripts": {
  ...
  "lint": "eslint 'src/**/*.{js,jsx,ts,tsx}'",
  "lint:fix": "eslint --fix 'src/**/*.{js,jsx,ts,tsx}'",
},
```
    
## Prettierの設定
1. PrettierとESLint用プラグインをインストール
```js
    npm i -D prettier eslint-config-prettier  
```
    
2. .eslintrc.jsonの書き換え
:::message alert
eslint-config-prettier 系の共有設定は必ず最後に書く。
∵他と競合するルール設定を上書きして調整するため
:::
```diff js
"extends": [
    "eslint:recommended",
    "plugin:@typescript-eslint/recommended",
    "plugin:@typescript-eslint/recommended-requiring-type-checking",
    "standard",
    "plugin:jsx-a11y/recommended",
    "plugin:react/recommended",
    "plugin:react/jsx-runtime",
    "plugin:react-hooks/recommended",
+  "prettier"
],
```

3. ESLint で設定してあったルールと Prettier で設定したルールが衝突してないか確認
```
npx eslint-config-prettier 'src/**/*.{js,jsx,ts,tsx}'
```
    
4. packege.jsonに以下を追加
```js
"scripts": {
  ...
"format": "prettier--write--loglevel=warn 'src/**/*.{js,jsx,ts,tsx,html,json,gql,graphql}'",
"fix": "npm run --silent format; npm run --silent lint:fix",
},
```
    
5. settings.jsonに以下を追加
VS Code のデフォルトのフォーマッタに Prettier を設定して、各種言語の保存時に自動整形が走るようにするため
```jsx
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "[graphql]": {
      "editor.formatOnSave": true
  },
  "[javascript]": {
      "editor.formatOnSave": true
  },
  "[javascriptreact]": {
      "editor.formatOnSave": true
  },
  "[json]": {
      "editor.formatOnSave": true
  },
  "[typescript]": {
      "editor.formatOnSave": true
  },
  "[typescriptreact]": {
      "editor.formatOnSave": true
  },
```

## huskyの設定
コミット前にリンタやコードフォーマッタ、テストのチェックを行うため導入。
ここではリンタを実行させるため行う。

1. huskyインストール
```
npm install --save-dev husky lint-staged
```
2. husky初期設定
```
npx husky init
```
3. package.jsonのスクリプトを編集
:::message
モノレポ構成でない場合は不要
:::
```diff js
  {
      ...
      "scripts": {
  -        "prepare": "husky"
  +        "prepare": "cd .. && husky reactapp1.client/.husky"
      },
      ...
  +      "lint-staged": {
  +        "src/**/*.{js,jsx,ts,tsx}": [
  +          "prettier --write --loglevel=warn",
  +          "eslint --fix --quiet"
  +        ],
  +        "src/**/*.{css,less,sass,scss}": [
  +          "stylelint --fix --quiet"
  +        ],
  +        "src/**/*.{html,json,gql,graphql}": [
  +          "prettier --write --loglevel=error"
  +        ]
  +      },
  }
```   
4. pre-commitスクリプトを編集
```diff js
- npm test
+ cd reactapp1.client && npx lint-staged && npm run test
```

# トラブルシューティング
## ESLint
### 「Parsing error: Cannot read file 'tsconfig.json’」というエラーが出る
"project": trueにするとtsconfig.jsonが見つかるまでフォルダをさかのぼってくれる
```js
"parserOptions": {
	...
  "tsconfigRootDir": "__dirname",
  "project": true
},
```
https://typescript-eslint.io/blog/parser-options-project-true/

### **.eslintignoreが効かない**
.eslintignoreがルートになるようワークスペースを開く
https://stackoverflow.com/questions/47236682/eslintignore-file-not-working

### 「No files matching the pattern "'src/**/*.{js,jsx,ts,tsx}'" were found. Please check for typing mistakes in the pattern.」とかいうエラーが出る
Windows環境でやってるせいかも。以下のようにscriptを書き換える
```js
  "lint": "eslint \"src/**/*.{js,jsx,ts,tsx}\"",
  "lint:fix": "eslint --fix \"src/**/*.{js,jsx,ts,tsx}\"",
  "format": "prettier--write--loglevel=warn \"src/**/*.{js,jsx,ts,tsx,html,json,gql,graphql}\"",
```
WSLで開発しような。
