---
title: "DTOとは何か"
---
前章のControllerの中に、以下のような記述がありましした。
```ts:cats.controller.ts
  @Post() // POST /cats
  create(@Body() createCatDto: CreateCatDto) {
    return 'This action adds a new cat';
  }
```
ここでいきなり出てきた```CreateCatDto```とはなんでしょうか？
これは、DTO（Data Transfer Object）と呼ばれるものです。

DTOは、ソフトウェア開発において、アプリケーションの異なるレイヤー間でデータを転送するためによく使われるデザインパターンです。
データをカプセル化し、アプリケーションの異なる部分間でデータを転送するための標準化された方法を提供したい、というのがDTOパターンの背後にある主な考え方のようです。

DTOは、データを保持するシンプルなオブジェクトで、場合によってはバリデーションのロジックを含むこともあります。ただし、具体的な処理（ビジネスロジックなど）は含まれません。
DTOは通常サーバー側で作成され、データベースや他のデータソースから必要な情報を取得してクライアントに送信されます。クライアント側では、このDTOを使ってデータをユーザーに表示したり、処理のためにサーバーへ再送信したりします。
